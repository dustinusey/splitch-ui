# My splitch app

Created with `create-splitch-app` and built on [`@splitch/ui`](https://github.com/dustinusey/splitch-ui).

```bash
npm install
npm run dev
```

- Brand color: `data-accent` on `<html>` and `defaultAccent` in `src/app/layout.tsx`.
- Update the design system: `npm update @splitch/ui` (follows `semver:^0.1.0` tags).
- Deploy: import the repo in Vercel, no config needed.
